# Marketing Campaign Performance & ROI Analysis

## Project Overview

This project analyzes marketing campaign performance across multiple dimensions, including ROI, revenue, conversions, engagement, target audience, acquisition cost, campaign type, and language.

The dataset was analyzed using PostgreSQL and SQL, with the results visualized through an interactive Tableau dashboard to identify campaign performance trends and support data-driven marketing decisions.

## Tools Used

- PostgreSQL
- SQL
- Tableau
- Kaggle

## Key Analysis

- Analyzed average ROI across campaign types and target audience segments.
- Compared engagement and ROI across different campaign strategies.
- Evaluated campaign performance based on acquisition cost categories.
- Analyzed monthly ROI trends and campaign performance by language.
- Compared campaign strategies across different audience segments.
- Identified the top-performing campaigns based on ROI.

## Project Workflow

1. Obtained the marketing campaign dataset from Kaggle.
2. Imported and analyzed the dataset using PostgreSQL.
3. Wrote SQL queries to explore campaign performance across key marketing dimensions.
4. Exported the analyzed data for visualization.
5. Built an interactive Tableau dashboard to present key insights and performance trends.
